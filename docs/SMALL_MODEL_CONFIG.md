# GeneDiffusion 小型模型配置

## 概述

为了快速测试和验证，我们提供了一个小参数量的模型配置，该模型使用全量数据（3.45M样本）进行训练，但参数量仅为13.12M，是标准模型（179M）的7.3%。

## 模型架构

### 核心参数
- **Hidden Size**: 256 (标准模型: 768)
- **Layers**: 4层 (标准模型: 12层)
- **Attention Heads**: 4个 (标准模型: 12个)
- **Intermediate Size**: 1024 (标准模型: 3072)
- **参数总量**: 13.12M

### 参数分布
```
Token Embedding:        1.05M (8.0%)
Species Embedding:      58.88K + 117.76K = 176.64K (1.3%)
Annotation Encoder:     5.40M (41.2%)
Transformer Layers:     5.40M (41.2%)
Output Projection:      1.05M (8.0%)
其他:                   ~0.3%
```

## 数据配置

### 全量数据训练
- **总样本数**: 3,450,000 (3.45M)
- **物种数**: 230个哺乳动物物种
- **每个物种样本数**: 15,000
- **序列长度**: 10kb (1,666个6-mer tokens)

### 批次配置
- **批次大小**: 256
- **梯度累积步数**: 2
- **有效批次大小**: 512
- **每个epoch步数**: 13,476

## 训练设置

### 训练参数
- **Epochs**: 50 (总步数: 673,800)
- **学习率**: 2e-4 (略高于标准模型)
- **Warmup步数**: 5,000
- **优化器**: AdamW
- **混合精度**: FP16

### 检查点设置
- **保存间隔**: 每2,000步
- **评估间隔**: 每500步
- **日志间隔**: 每50步

## 使用方法

### 启动训练
```bash
# 使用提供的脚本
bash scripts/train_small_model.sh

# 或者直接使用torchrun
torchrun --nproc_per_node=4 --master_port=29500 \
    src/train.py \
    --config configs/train_config_small.yaml \
    --output_dir outputs/small_model_test
```

### 配置文件
主配置文件位于 `configs/train_config_small.yaml`

## 性能预估

### 训练时间
- **每步时间**: ~0.5秒 (4个GPU)
- **总训练时间**: ~94小时 (约4天)

### 内存使用
- **模型参数**: ~50MB
- **梯度**: ~50MB
- **优化器状态**: ~100MB
- **激活值**: 取决于批次大小

### GPU要求
- **最小**: 1个GPU (16GB显存)
- **推荐**: 4个GPU (更快的训练速度)
