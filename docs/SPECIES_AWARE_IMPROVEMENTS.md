# GeneDiffusion物种感知机制增强

## 概述

GeneDiffusion模型现在具有增强的物种感知能力，能够更好地利用230个哺乳动物物种的信息来生成物种特异性的DNA序列。

## 核心改进

### 1. 增强的物种嵌入（SpeciesAwareEmbedding）

原始实现只是简单地将物种嵌入与序列特征拼接。现在的实现包含：

- **物种嵌入向量**：将物种ID映射到d_model/4维的嵌入空间
- **FiLM调制**：使用Feature-wise Linear Modulation，为每个物种学习特定的缩放(scale)和偏移(shift)参数
- **自适应特征融合**：`x_modulated = x_fused * scale + shift`

这种方法允许模型学习物种特定的特征变换，更好地捕捉不同物种的序列特性。

### 2. 物种条件层归一化（SpeciesConditionedLayerNorm）

不同物种的DNA序列可能具有不同的统计特性（如GC含量、密码子使用偏好等）。物种条件层归一化：

- 为每个物种学习独立的归一化参数（γ和β）
- 保持序列的标准化，同时允许物种特定的调整
- 帮助模型更好地适应不同物种的序列分布

### 3. 物种信息的深度集成

- **早期融合**：在序列编码的最开始就引入物种信息
- **持续调制**：在每个Transformer层中都使用物种条件层归一化
- **端到端学习**：物种特定参数与主模型一起训练

## 生物学意义

这些改进反映了真实的生物学差异：

1. **GC含量差异**：不同物种的基因组GC含量差异很大（如人类约41%，某些细菌可达70%）
2. **密码子使用偏好**：不同物种偏好使用不同的同义密码子
3. **基因组结构**：不同物种的基因密度、内含子长度等存在差异
4. **进化约束**：不同物种受到的进化压力不同

## 训练优势

1. **更快的收敛**：物种特定的归一化帮助模型更快地适应不同物种的数据
2. **更好的泛化**：FiLM调制允许模型学习物种间的共性和差异
3. **可解释性**：可以分析学习到的物种特定参数，理解模型如何区分不同物种

## 使用示例

```python
# 模型会自动利用物种信息
model = GeneDiffusionModel(
    vocab_size=4099,
    num_species=230,  # 支持230个哺乳动物物种
    d_model=512,
    n_layers=8,
    n_heads=8,
    d_ff=2048
)

# 生成特定物种的序列
species_ids = torch.tensor([0])  # 例如：人类
generated_seq = model.sample(
    batch_size=1,
    seq_len=1000,
    annotations=annotations,
    species_ids=species_ids,  # 物种信息被深度利用
    num_steps=100
)
```

## 未来改进方向

1. **物种层次结构**：利用物种的系统发育关系（如灵长类、啮齿类等）
2. **跨物种迁移学习**：利用相近物种的知识辅助稀有物种的序列生成
3. **物种特定的生成控制**：允许用户指定物种特定的生成参数（如目标GC含量）
4. **多物种联合建模**：同时考虑多个物种的同源序列

## 实验建议

1. **物种特定评估**：分别评估模型在不同物种上的表现
2. **消融实验**：比较有无物种条件的模型性能
3. **物种嵌入分析**：可视化学习到的物种嵌入，看是否反映系统发育关系
4. **参数分析**：分析不同物种的scale/shift参数，理解模型学到的物种特性
