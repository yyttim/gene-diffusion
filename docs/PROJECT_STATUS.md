# GeneDiffusion 项目状态

## 项目概述
GeneDiffusion是一个基于Masked Diffusion架构的哺乳动物DNA序列生成模型，灵感来源于Evo2的设计理念。项目专注于利用约230个哺乳动物物种的基因组数据，实现生物学约束下的高质量DNA序列生成。

## 最新进展 (2024-12)

### ✅ 已完成

#### 1. 技术方案重新设计
- **基于实际数据调整创新点**：移除了需要额外数据的功能（如3D结构预测、表观遗传学等）
- **聚焦可实现功能**：
  - 物种感知学习（230个哺乳动物物种）
  - 注释引导生成（5种GFF注释类型）
  - 边界感知机制（基于GFF_Start/End）
  - 局部序列特征学习

#### 2. 模型架构优化
- **调整模型规模**：
  - Small: 50M参数
  - Base: 200M参数
  - Large: 800M参数
- **核心组件重构**：
  - SpeciesAwareEmbedding：物种特异性学习
  - BoundaryAwareAttention：功能元件边界感知
  - LocalSequenceEncoder：局部模式捕获
  - 简化的AnnotationEncoder：处理5种注释类型

#### 3. 深度数据分析（新完成）
- **数据规模确认**：
  - 实际包含230个物种（远超预期）
  - 序列长度范围：970bp到248,956,422bp
  - 注释文件：32-273MB，序列文件：1.9-4.1GB
- **关键发现**：
  - 所有物种都包含5种目标注释类型
  - 序列中存在大量N（未知碱基）
  - 注释密度分布不均
- **数据限制识别**：
  - 无表达量、3D结构、表观遗传学数据
  - 无进化树和功能验证信息

#### 4. 数据处理实现（新完成）
- **GenomicDataset类**：
  - 完整的数据加载pipeline
  - 智能物种映射（species_mapping.py）
  - 滑动窗口分片（5k窗口，50%重叠）
  - 注释优先级处理（CDS > exon > tRNA > lncRNA > gene）
  - 流式处理大文件
- **数据增强**：反向互补序列生成
- **DNATokenizer**：处理ACGTN和特殊token
- **AnnotationProcessor**：多层注释融合

#### 5. 配置系统完善
- 物种映射配置：完整的230个物种文件映射
- 训练配置：small/base/large三套方案

#### 6. Masked Diffusion 验证（新完成）
- **确认为真正的Masked Diffusion实现**：
  - 前向扩散：随机mask比例t∈[0,1]
  - 损失函数：正确实现L(θ) = -E[1/t ∑ 1[x_t^i = MASK] log p_θ(x_0^i|x_t)]

- **创新特性验证**：
  - 注释感知mask策略（功能区域保护）

## 技术洞察

### 数据处理策略
1. **长序列处理**：必须分片，不能直接处理整条染色体
2. **注释稀疏性**：设置最小注释覆盖率(10%)过滤无信息片段
3. **物种平衡**：限制每个物种最多1000个片段，避免偏差

### 模型设计原则
1. **不依赖缺失信息**：避免需要表达量、结构等数据的功能
2. **从数据学习模式**：让模型自己发现进化保守性
3. **注释作为软约束**：不强制但引导生成
