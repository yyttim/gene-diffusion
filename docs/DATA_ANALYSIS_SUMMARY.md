# GeneDiffusion 数据分析总结

## 数据概况

### 数据规模
- **物种数量**: 约230个哺乳动物物种（文档提到约100个，实际更多）
- **数据格式**: CSV格式的序列和注释文件
- **文件大小**: 
  - 注释文件: 32-273MB
  - 序列文件: 1.9-4.1GB

### 数据结构
1. **序列数据** (`data_stage3/`)
   - 列: `Sequence ID`, `Sequence`
   - 序列长度差异极大: 970bp到248,956,422bp（2.5亿bp）
   - 包含ACGTN字符（N表示未知碱基）

2. **注释数据** (`data_stage2/`)
   - 列: `Sequence ID`, `GFF_Type`, `GFF_Id`, `GFF_Start`, `GFF_End`
   - 注释类型众多，但只关注5种: exon, cds, lnc_rna, gene, trna

## 关键发现

### 1. 数据特征
- **序列长度极端不均**: 从不到1kb到整条染色体（>200Mb）
- **高N含量**: 某些序列（如人类1号染色体）开头有大量N
- **注释密度变化大**: 不同区域的注释密度差异显著
- **所有物种都包含5种目标注释类型**

### 2. 数据中包含的信息
✓ DNA序列（ACGTN）  
✓ 5种主要注释类型及位置  
✓ 约230个哺乳动物物种  
✓ 序列ID和位置信息  

### 3. 数据中缺失的信息
✗ 基因表达量数据  
✗ 蛋白质结构信息  
✗ 染色质状态/表观遗传学数据  
✗ 进化保守性分数  
✗ 功能验证数据  
✗ 细胞类型特异性信息  
✗ 时序表达数据  
✗ 物种进化关系树  

## 模型设计适应性调整

### 1. 移除的功能（因缺乏数据支持）
- ❌ 3D结构预测
- ❌ 表观遗传学预测
- ❌ 基于表达量的功能预测
- ❌ 进化轨迹模拟（需要系统发育树）
- ❌ 跨物种功能转移（需要同源性数据）

### 2. 保留和强化的功能
- ✅ **物种感知学习**: 为每个物种学习独特的序列模式
- ✅ **注释引导生成**: 利用5种GFF注释类型指导序列生成
- ✅ **边界感知机制**: 基于GFF_Start/End学习功能元件边界
- ✅ **局部序列特征**: 学习密码子偏好、剪接位点等
- ✅ **生物学约束**: GC含量控制、ORF保持、序列复杂度

### 3. 数据处理策略
1. **序列分片**:
   - 窗口大小: 5000bp
   - 重叠: 50%（步长2500bp）
   - 优先选择注释密集区域

2. **物种平衡**:
   - 每个物种最多1000个片段
   - 避免大基因组物种主导

3. **注释处理**:
   - 优先级: CDS > exon > tRNA > lncRNA > gene
   - 最小注释覆盖率: 10%

4. **数据增强**:
   - 反向互补序列
   - 保持注释一致性

## 训练建议

### 1. 初始训练
- 从主要物种开始（人、鼠、牛、猪等）
- 验证基础功能后扩展到全部物种

### 2. 计算资源估算
- Small模型(50M): 单GPU可训练
- Base模型(200M): 建议2-4 GPU
- Large模型(800M): 建议4-8 GPU

### 3. 训练策略
- 使用Masked Diffusion，随机mask比例
- 逐步引入生物学约束损失
- 动态调整mask比例（初期高，后期低）

## 注意事项

1. **内存管理**: 序列文件很大，需要流式处理
2. **N的处理**: 可作为特殊token或随机替换
3. **长序列处理**: 必须分片，不能加载整条染色体
4. **注释噪声**: 某些注释可能不准确或不完整
