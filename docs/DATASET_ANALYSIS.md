- **序列总数**: 3,000,000 条
- **序列长度**: 每条序列精确10,240 bp (10kb + 240bp)
- **字符类型**: 仅包含小写DNA碱基字母 (a, t, c, g)

4. **大规模**: 3M样本，总计约30.7Gb的序列数据

## 与GeneDiffusion的兼容性

### 1. 长度匹配
- 数据集: 10,240 bp
- 模型配置: 10,000 bp (10kb)
- **处理方案**: 可以截取前10,000bp使用，或调整模型接受10,240bp

### 2. 6-mer Tokenization
- 10,000bp → 1,666个6-mer tokens（10,000/6 ≈ 1,666）
- 10,240bp → 1,706个6-mer tokens（10,240/6 ≈ 1,706）

### 3. 批处理建议
- **批次大小**: 考虑到29GB的数据量，建议使用较小的批次（16-32）
- **内存需求**: 每个样本约10KB，批次32需要约320KB（仅序列数据）

## 数据加载建议

```python
# 简单的数据加载示例
def load_sequences(file_path, max_length=10000):
    sequences = []
    with open(file_path, 'r') as f:
        for line in f:
            # 截取到模型需要的长度
            seq = line.strip()[:max_length]
            sequences.append(seq)
    return sequences
```

## 注意事项

1. **文件大小**: 29GB的文件需要足够的内存和存储空间
2. **I/O性能**: 建议使用SSD存储以提高读取速度
3. **预处理**: 可能需要将数据分割成更小的批次文件
4. **序列长度**: 需要决定是使用10,000bp还是完整的10,240bp
