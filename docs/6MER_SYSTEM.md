# GeneDiffusion 6-mer Token系统说明

## 概述

GeneDiffusion使用6-mer（6个连续碱基）作为基本token单位，而不是传统的单碱基token。这是一个重要的架构决策，显著影响了模型的性能和能力。

## 核心概念

### 什么是6-mer？
- 6-mer是指6个连续的DNA碱基序列
- 例如：`ATCGAT`、`GCTAGC`等
- 总共有4^6 = 4096种可能的6-mer组合

### 词汇表构成
- **6-mer tokens**: 0-4095（对应所有可能的6-mer）
- **特殊tokens**:
  - `[MASK]`: 4096
  - `[PAD]`: 4097
  - `[UNK]`: 4098（用于包含N的6-mer）
- **总词汇表大小**: 4099

## 技术实现

### 序列编码
```python
# 原始序列
sequence = "ATCGATCGATCGATCG"  # 16bp

# 6-mer编码
tokens = [867, 1590]  # 对应 ["atcgat", "cgatcg"]
```

### 序列长度变化
- 原始序列：5000bp
- 6-mer tokens：~833个（5000/6）
- 压缩比：6:1

### 注释处理
- 碱基级别注释转换为6-mer级别
- 使用多数投票或优先级规则确定每个6-mer的注释类型

## 优势

### 1. 计算效率
- **序列长度减少6倍**：降低了Transformer的O(n²)复杂度
- **内存使用减少**：更短的序列需要更少的内存
- **训练速度提升**：处理更少的token数量

### 2. 生物学意义
- **捕获局部模式**：6-mer能够捕获重要的生物学模式（如限制性酶切位点、转录因子结合位点）
- **密码子感知**：2个6-mer可以完整表示4个密码子
- **减少噪音**：单碱基变异的影响被平均化

### 3. 模型能力
- **更丰富的语义**：每个token包含更多信息
- **更好的长程依赖**：相同的注意力窗口可以覆盖更长的序列
- **更稳定的训练**：词汇表大小适中（4096 vs 4或20）

## 限制和注意事项

### 1. 序列长度要求
- 输入序列最好是6的倍数
- 非6倍数的序列末尾会被截断
- 例如：14bp序列只会使用前12bp

### 2. 精度权衡
- 无法进行单碱基级别的编辑
- 点突变需要重新编码整个6-mer
- 插入/删除操作会影响后续所有6-mer

### 3. 特殊情况处理
- 包含N的6-mer编码为`[UNK]`
- 序列边界处理需要特别注意

## 与其他方法的比较

| 方法 | Token数 | 词汇表大小 | 优势 | 劣势 |
|------|---------|------------|------|------|
| 单碱基 | n | 4-20 | 精确到碱基 | 序列太长 |
| 3-mer | n/3 | 64 | 对应密码子 | 词汇表较小 |
| **6-mer** | **n/6** | **4096** | **平衡性好** | **固定粒度** |
| BPE | 可变 | 可变 | 自适应 | 生物学意义不明确 |

## 未来改进方向

1. **可变k-mer**：根据序列特征动态选择k值
2. **重叠k-mer**：使用滑动窗口增加分辨率
3. **层次化token**：结合不同k值的多尺度表示
4. **位置编码优化**：考虑6-mer边界的特殊位置编码

## 总结

6-mer token系统是GeneDiffusion的核心创新之一，它在计算效率和生物学表达能力之间取得了良好的平衡。虽然牺牲了单碱基级别的精度，但获得了更高效的序列建模能力和更好的长程依赖捕获能力。
