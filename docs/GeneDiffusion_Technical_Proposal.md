# GeneDiffusion Technical Proposal

## 项目概述
GeneDiffusion是一个创新的DNA序列生成模型，灵感来源于Evo2的设计理念，采用Masked Diffusion架构，专门针对哺乳动物基因组序列的生成和功能理解。该模型基于230个哺乳动物物种的数据，结合GFF注释信息，实现基于生物学约束的DNA序列生成。

## 核心创新点（基于实际数据可实现）

### 1. 哺乳动物特化的序列模式学习
- **基于230个哺乳动物物种数据**：学习哺乳动物特有的序列模式和进化保守性
- **物种间共享表示**：通过跨物种训练学习通用的哺乳动物基因组特征
- **物种特异性编码**：为每个物种学习独特的嵌入表示

### 2. 注释引导的扩散过程
- **五类注释集成**：利用exon、cds、lnc_rna、gene、trna注释信息
- **边界感知机制**：基于GFF_Start和GFF_End信息，学习功能元件的边界特征
- **功能区域优先保护**：在扩散过程中，对标注的功能区域采用不同的masking策略

### 3. 局部序列特征增强
- **密码子使用偏好学习**：在CDS区域学习密码子使用模式
- **剪接位点识别**：在exon边界学习剪接信号
- **启动子/终止子模式**：在gene边界学习调控序列特征

### 4. 多尺度序列生成策略
- **滑动窗口生成**：虽然训练限制在5k，但通过重叠窗口生成更长序列
- **上下文一致性保持**：确保窗口间的序列连贯性
- **注释连续性约束**：保持跨窗口的注释一致性

### 5. 生物学约束的损失函数
- **GC含量约束**：基于物种特异的GC含量分布
- **开放阅读框(ORF)保持**：在CDS区域维持正确的阅读框
- **序列复杂度控制**：避免生成过度重复的序列

## 技术架构调整

### 模型规模（更合理的设置）
- **Small模型**: 50M参数（d_model=512, n_layers=8）
- **Base模型**: 200M参数（d_model=768, n_layers=12）
- **Large模型**: 800M参数（d_model=1024, n_layers=24）

### 训练策略
- **阶段1**: 基础序列建模（仅DNA序列）
- **阶段2**: 注释条件生成（加入GFF注释）
- **阶段3**: 物种特异性微调（针对特定物种优化）

### 移除的不切实际功能
- ~~3D结构预测~~（需要结构数据）
- ~~跨物种功能预测~~（需要功能实验数据）
- ~~进化轨迹模拟~~（需要时间序列数据）
- ~~表观遗传学预测~~（需要甲基化等数据）

## 数据处理优化

### 基于实际数据的处理流程
1. **序列预处理**
   - 统一小写字母表示
   - 处理模糊碱基(N)
   - 5k长度分片，保持注释完整性

2. **注释标准化**
   - 将GFF_Type统一为小写
   - 创建token级别的标签：`<t_exon>`, `<t_cds>`, `<t_lnc_rna>`, `<t_gene>`, `<t_trna>`
   - 处理重叠注释的优先级

3. **物种信息编码**
   - 为每个物种创建唯一ID
   - 构建物种进化树信息（如果可获得）

## 评估指标

### 序列质量评估
- **碱基组成一致性**：生成序列与真实序列的碱基频率比较
- **k-mer分布相似性**：评估局部序列模式
- **注释边界准确性**：评估生成序列的功能元件边界

### 生物学合理性评估
- **ORF完整性**：CDS区域的开放阅读框比例
- **剪接位点保守性**：GT-AG规则的遵守程度
- **密码子使用偏好**：与物种特异偏好的一致性

## 应用场景

### 基于现有数据可实现的应用
1. **序列补全**：填补测序空缺
2. **变异效应预测**：评估突变对序列功能的影响
3. **合成序列设计**：生成具有特定注释模式的新序列
4. **跨物种序列迁移**：在相似物种间转换序列特征

### 未来扩展方向
- 整合更多物种数据
- 加入RNA-seq表达数据
- 结合ChIP-seq等功能数据
